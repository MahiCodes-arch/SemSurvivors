# SemSurvivors

This is an aid to the student who want to make smarter academic decision using their own college data.
It introduces 4 core functionalities:
1- Smart Bunk Calculator
2- Syllabus Tracker
3- AI Study Planner
4- Daily Study Planner

It covers the AI domains such as Machine Learning and Data Science.
This project also features mathematical concepts.
